# برای تارای من 💙

این سایت کاملاً استاتیک است و به سرور یا نصب پکیج نیاز ندارد.

## اجرا
فایل `index.html` را باز کنید. فایل `moon.jpg` باید در کنار آن باشد.

## انتشار در GitHub Pages
1. یک repository بسازید.
2. `index.html` و `moon.jpg` را در ریشه repository آپلود کنید.
3. به Settings → Pages بروید.
4. در Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
5. Branch را روی `main` و پوشه را روی `/ (root)` بگذارید و Save کنید.
6. لینک عمومی نمایش‌داده‌شده را به اشتراک بگذارید.

تصویر ماه از نظر بایت‌ها دقیقاً بدون تغییر نگه داشته شده؛ فقط پسوند اشتباه `.png` به `.jpg` اصلاح شده است.
